How the capacity is calculated
  1. Only finished tests count: completed, or stopped by the fail-safe. Tests you stopped yourself (partial) are shown in the history but never counted.
  2. Only comparable workloads count: 40–60 messages per chat per minute and at least 2 minutes at full load. For each chat level the newest such test is used.
  3. Walking the levels upwards, the recommended capacity is the highest level reached before the first level that is not a PASS inside all safety margins (CPU, RAM, P95 latency and error rate below the margin values in Thresholds).
  4. The warning zone is that first level when it ended in WARNING (or passed without keeping the margins). The observed failure is the lowest level that ended in FAIL.
  5. A better result at a higher level after a worse one is ignored. Nothing above the highest tested level is ever claimed.

Thresholds

PASS / WARNING / FAIL limits and safety margins. These are reasonable starting values, not scientifically proven; adjust them to what you consider acceptable. Each report keeps the thresholds it was judged by.
